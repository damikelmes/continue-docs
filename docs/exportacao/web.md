# <DocHeadingIcon icon="globe-outline" color="#67E8F9" /> Exportar para Web

A versão **Web (HTML5)** abre o jogo diretamente em um navegador. Ela pode ser publicada no itch.io ou em outro serviço que aceite jogos para Web.

## <DocHeadingIcon icon="options-outline" color="#67E8F9" /> Preparar o jogo

Nas **Configurações do projeto**, confira o nome, a versão, a orientação, a resolução base e o modo de ajuste em outras telas. Essas escolhas definem como a área visível do jogo se adapta ao espaço disponível no navegador.

## <DocHeadingIcon icon="download-outline" color="#67E8F9" /> Gerar o ZIP

1. Abra **Exportar** e depois **Web (HTML5)**.
2. Toque em **Jogo para Web**.
3. Confira o nome do ZIP, o formato e a tela base.
4. Toque em **Gerar jogo Web**.
5. Aguarde a preparação terminar e compartilhe o ZIP.

O pacote já é criado com a página inicial do jogo e os demais arquivos organizados para funcionar juntos. Não altere a estrutura antes de publicar.

## <DocHeadingIcon icon="cloud-upload-outline" color="#FA5C5C" /> Publicar no itch.io

1. Crie ou edite a página do jogo no itch.io.
2. Escolha o tipo de projeto **HTML Game**.
3. Envie o ZIP gerado pela Continue sem extrair.
4. Marque o arquivo para ser executado no navegador, se essa opção aparecer.
5. Salve a página e abra a versão publicada para testar.

Se você gerar uma nova versão, envie o novo ZIP na mesma página do jogo e confirme que ele substituiu a versão anterior.

## <DocHeadingIcon icon="server-outline" color="#67E8F9" /> Usar em outro serviço

Em outros serviços de hospedagem, envie o conteúdo do ZIP mantendo todas as pastas e arquivos juntos. O serviço deve permitir páginas e jogos HTML5.

Quando houver uma opção de arquivo inicial, use a página `index.html` que já vem no pacote.

## <DocHeadingIcon icon="save-outline" color="#C4B5FD" /> Encontrar uma versão novamente

Os pacotes concluídos aparecem nas exportações Web salvas do projeto. Você pode compartilhar novamente ou excluir versões antigas.

::: tip Teste a versão publicada
Além do visualizador da engine, abra o link do jogo em um celular e em um computador. Confira controles, animações, carregamento, tela cheia e adaptação da câmera.
:::
